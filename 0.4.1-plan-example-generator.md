# 0.4.1 — Pasted Image Example Generator

## Goal

Extend the existing harness generator with an artist-facing writing stub. An
artist pastes background image URLs, selects the normal wagon settings, and
uses the existing `regen` action to see a complete Snowfall example with
writeable text placeholders around every visual. A local gradient remains
available for testing without an image URL.

## Controls

The tool lives in the fixed left `#gen` panel:

- `image URLs, one per line` accepts blank lines and ignores lines beginning
  with `#`.
- `include gradient` adds one local CSS gradient scene after pasted images.
- There is no second generate action. The existing `regen (r)` button rebuilds
  the complete test story, including the pasted-image examples.
- `copy example outerHTML` lives with the QA controls because copying the
  generated fixture is a QA/authoring action, not a second generator.
- The read-only HTML result remains beside the image list so the artist can
  inspect or manually select it if clipboard access is blocked.

The existing `mode`, `size`, `data-dir`, `flow`, `nesting`, `sticks`,
`data-bg/fg/style`, and `script events` controls are the settings source. A
`mixed` choice is deterministic for the current harness seed. Changing the
image list or gradient checkbox rebuilds on change; `regen` also rebuilds
settings and the preview together.

## Generated contract

```html
<div class="snow-example-container" data-snowfall-example="image-list">
	<div class="snow-example-heading">Pasted examples</div>
	<section class="snow-example-scene">
		<h3 class="snow-example-title">pasted image 1</h3>
		<p class="snow-example-copy">Write text here…</p>
		<div class="snow-bg" data-example-kind="image" data-mode="cover"
			style="background-image:url(&quot;scene.jpg&quot;)"></div>
		<p class="snow-example-copy">Write text here…</p>
	</section>
</div>
```

- Every visual is a normal `.snow-bg`, so the existing engine owns its
  dimensions, sticky parking, direction, and transform.
- Pasted values are escaped for both HTML attributes and quoted CSS URLs.
  The generated gradient is a static local CSS `linear-gradient`.
- Each scene contains visible text placeholders before and after its
  background. These are the prose stubs an artist replaces after copying the
  outerHTML.
- Optional scene data attributes, sticks, and inert `type="txt"` event blocks
  follow the existing generator vocabulary.
- The clean generated outerHTML is kept separately from the live preview, so
  engine markers, transforms, and measurement styles never leak into copied
  markup.
- The preview is appended before the existing tail; regular generated
  chapters remain intact and the example scenes participate in the same
  engine refresh and diagnostics.

## Runtime rules

- No build step, modules, network dependency, or persistence of pasted URLs in
  the location hash.
- Clipboard API is preferred. A hidden textarea and `execCommand('copy')`
  provide the `file://` fallback.
- An empty list is valid when the gradient is enabled. If both sources and
  gradient are absent, the example container is omitted and the QA copy
  button is disabled.

## Acceptance criteria

- [ ] The left tools show the paste field, gradient option, and generated HTML
  output; there is no duplicate generate button.
- [ ] The existing `regen (r)` action rebuilds one scene for every non-empty
  pasted line, plus one local gradient when enabled.
- [ ] Each scene has text placeholders before and after its visual.
- [ ] Changing an existing wagon setting and pressing regen changes both the
  preview and the copied container markup.
- [ ] The copy action is located in the QA controls and copies the complete
  `.snow-example-container` element, not only its children.
- [ ] External image URLs are not silently rewritten; the gradient remains
  local and does not add a network request.
- [ ] Existing generator, event QA, and no-engine fallback still work after
  the example preview is present.
- [ ] Opening `index.html` directly remains supported; blocked clipboard access
  leaves the output selectable and explains what happened.
