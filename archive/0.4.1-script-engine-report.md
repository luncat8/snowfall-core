Plan **0.4.1 (Script Policies, Choices and Save Slots)** has been implemented and verified.

### Summary of Changes

1. **Engine Core (`snowfall.js`)**
   - **Policies per script (`eventsMeasure`)**:
     - `data-times`: `'many'` (default) vs `'once'` (pre-sets latch flags when all scripts at an anchor have already fired in `store.fired`, and filters inside `fireAnchor`). Survives reload and re-arm; restored by `Snowfall.reset()`.
     - `data-dir`: `'forward'` (default) vs `'both'` (fires thresholds on upward/reverse scroll with `detail.dir = -1`).
     - `data-skip`: `'replay'` (default) vs `'none'` (filtered in `fireAnchor` so sibling skip scripts still fire).
     - `data-id`: stable identity; derived via deterministic FNV-1a hash if missing (`fnv1a(code)`). Duplicate IDs warn once and demote duplicates to `'many'`.
   - **Thresholds & State Machine (`eventsFrame`)**:
     - Pre-allocates `E.side` (`Uint8Array`) tracking the last side of each threshold (view, center, parked, end).
     - Tracks frame scroll direction `frameDir` (`+1` or `-1`), preserving previous non-zero sign during resting frames.
     - Upward reverse crossing (`oldSide & ~curSide`) fires `both` scripts with `detail.dir = -1`, leaving `forward` scripts and `skip` silent.
     - `eventsFrame` body contains **no store accesses** and **no object/array allocations**.
   - **Persistent Result Store**:
     - Schema: `{ v: 1, story, slot: 0, at, vars: {}, keys: {}, fired: {} }`.
     - Key derivation: `snowfall:${story}:0`, with `story` derived from `<html data-story="...">`, `<meta name="story">`, or pathname tail.
     - Scalar validation on `vars` and `keys`: finite numbers, strings, booleans, and null are accepted; non-scalars warn and are dropped.
     - Safe fallback: caught `localStorage` exceptions (private browsing, quota) fallback to in-memory store with `Snowfall.store.persistent === false`.
     - Autosave debounced at 250ms, flushed synchronously before exports and on `pagehide` / `beforeunload`.
     - Methods: `Snowfall.get(key, fallback)`, `Snowfall.set(key, value)`, `Snowfall.sum(prefix)`, `Snowfall.save()`, `Snowfall.load(json)`, `Snowfall.exportJSON()`, `Snowfall.importJSON(text)`, `Snowfall.reset(mask)`, and `Snowfall.store` debug getter.
   - **Choice Primitive (`Snowfall.ask` & `Snowfall.answer`)**:
     - In replay mode (`skip`), resolves synchronously with `mode = 'saved'` or `'default'`, rendering zero DOM.
     - In live mode, renders built-in fixed prompt (`.snow-prompt`, `z-index: 60` on `<body>`, outside `#app`) or delegates to `Snowfall.onChoice` hook.
     - Live answer recorded in `store.keys` *before* continuation `done(value, 'live')` runs.
     - **Abandon rule**: if anchor reaches `end` (`d < 0`) before an answer, resolves with stored value (`'saved'`) or fallback (`'default'`), marks anchor skipped, and clears pending prompt.
     - Exactly-once enforcement: duplicate `ask` for a pending key or `answer` for an unknown/resolved key warns once and is ignored.

2. **Harness & UI (`harness.js`, `index.html`)**
   - **Generator**: emits in every story an `ask` dialog with options, an `ask` minigame with `options = null` plus trigger button, a `data-times="once"` script, and a `data-dir="both"` script without perturbing `LOG` counts for `qEvents`.
   - **Diagnostics**: `dstats` prints `store.persistent`, counts of `vars`/`keys`/`fired`, and pending prompt count.
   - **Controls**: added `save ↓` (downloads JSON), `load ↑` (file picker import), and `clear save` (`Snowfall.reset()`).
   - **Probe `qChoices`**: exercises live `ask`, options=null, abandon, replay `saved`/`default`, `data-times="once"` across reloads and resets, `data-dir="both"` direction legs, `data-skip="none"`, byte-identical JSON round-trip, storage quota fallback, cold load mid-doc, and static zero-allocation check on `eventsFrame`.
   - Wired `qChoices` into `qaAll()`.

3. **Node Gate Suite (`test/scripts.js`)**
   - Comprehensive test suite covering pure store serialization, scalar validation, sum calculations, story-prefixing, in-memory degradation, and synthetic scroll sequences exercising `many`/`once`/`both`/`skip`/`ask`.
   - All 6 gates in `node test/run.js` are green (111/111 checks in `test/scripts.js`).
