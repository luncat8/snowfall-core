Ниже — самостоятельная тестовая страница для прототипа visual novella engine.

Основные решения:

- `.bg` остаётся в обычном DOM-потоке и служит якорем.
- Настоящий фон рисуется отдельным fixed-слоем.
- Фон движется вместе с якорем.
- При достижении `top: 0` фон «паркуется».
- Следующий фон выталкивает предыдущий вверх.
- Размеры глав могут быть любыми.
- Можно смешивать обычный текст, `section`, `.bg`, вложенные элементы и скрипты.
- `data-bg-size` поддерживает:
  - `cover`
  - `contain`
  - `original`
  - `fixed`
- События:
  - `view`
  - `center`
  - `end`
  - `skip`
- В тесте используются только градиенты и SVG data URI, без внешних картинок.


### Как задавать размер фона

```html
<div
	class="bg"
	data-bg-size="cover"
	style="background-image: linear-gradient(red, orange);">
</div>
```

```html
<div
	class="bg"
	data-bg-size="contain"
	style="background-image: url(image.svg);">
</div>
```

```html
<div
	class="bg"
	data-bg-size="original"
	style="
		height: 600px;
		background-image: url(image.svg);
	">
</div>
```

```html
<div
	class="bg"
	data-bg-size="fixed"
	data-fixed-size="512px 512px"
	style="background-image: url(image.svg);">
</div>
```

Лучше задавать размер именно через `data-bg-size`, а не перегружать обычный `background-size`. Тогда:

- `background-size` остаётся стандартным CSS-свойством;
- `data-bg-size` отвечает за поведение движка;
- `data-fixed-size` задаёт специальный размер только для режима `fixed`.

### Важный момент

В текущем прототипе фоны двигаются вертикально и толкают друг друга в DOM-порядке. Это наиболее устойчивый базовый вариант.

`data-dir="left|right|up|down"` лучше добавлять отдельным режимом, потому что горизонтальное движение требует другой геометрии:

- отдельная ось координат;
- отдельные размеры `width/height`;
- другой порядок столкновений;
- обратная математика при прокрутке назад.

Основная вертикальная модель при этом уже обратима: позиция каждого фона вычисляется заново из его DOM-позиции, а не накапливается через `transform`. Поэтому ошибки вида «фон постепенно уплыл» или «после прокрутки назад он исчез» не должны появляться.
