I. Свободное размещение

VN v3. Движок теперь автоматически находит все <div class="bg"> в HTML — где бы автор их ни поставил: внутри секции, между абзацами, перед заголовком.

Каждый .bg — отдельный «вагон» в общей последовательности. Ниже — первый вагон. У него все 4 события: view / center / end / skip. Смотрите в Event Log слева снизу — там появятся сообщения.

Текст поверх первого фона (bg-size: cover, dir=up). Фоновое изображение заполняет весь экран.

Дальше будет второй вагон с bg-size: contain и направлением left.

1.1 — contain + left

Этот вагон использует data-bg-size="contain" — изображение вписывается в экран, оставляя чёрные полосы по бокам. Направление выезда — влево.

У этого вагона только события view и end — без center и skip. Это нормально — автор решает, какие события нужны.

Скролльте дальше — третья секция с длинной главой (parking test).

II. Полдень — original size (LONG parking)

Эта секция использует theme-noon. Тема интерполируется из рассвета — цвета меняются плавно. А фон использует data-bg-size="original" — изображение показывается в натуральном размере (1920×1080), центрируется, может не заполнять весь экран если viewport меньше.

Длинная глава (~300vh) — стресс-тест парковки. HUD показывает car 3 · PARKED с нарастающей длительностью. Тема остаётся стабильной noon · 100%.

Скролльте медленно — события view и center сработают по очереди. Скролльте быстро — возможно сработает skip.

Или кликните на боковую точку IV, чтобы перепрыгнуть через эту секцию — тогда для bg3 сработает событие skip (потому что вы прошли мимо, не просмотрев).

Inline-изображение внутри секции. Движок его не трогает — это обычный <img> в потоке.

Ещё немного текста для длины...

Скролльте дальше — будет секция с фиксированным размером фона 400×300.

III. Золотой час — fixed size 400×300

Эта секция с темой theme-golden. Фон — data-bg-size="400px 300px" (любое CSS-значение принимается). Изображение рендерится ровно 400×300px, центрируется на экране.

Вагон поедет вправо (dir=right). Маленькая картинка 400×300 — отличный способ показать «сфотографированный момент».

Дальше — закат с направлением вниз.

IV. Закат — dir=down

Тема интерполируется в закат (теплее, темнее, виньетка). Фон cover, направление вниз — вагон уезжает вниз с z-index boost, чтобы быть видимым поверх следующего.

Этот вагон без события end — автор может не подписываться на все события. HUD всё равно покажет, когда вагон уедет.

V. Ночь — LONG parking test (skip via dot)

Тема плавно перешла в ночь. Это снова длинная глава (~250vh) — парковка.

Тест skip: кликните на боковую точку VII (indoor), чтобы перепрыгнуть через эту секцию. Когда вы приземлитесь на VII, движок обнаружит, что bg6 был пропущен (его низ выше viewport top, но view никогда не сработал) — и запустит событие skip.

Scroll slowly through this section normally — events view → center → end will fire in sequence.

Или прокрутите обратно вверх — состояние каждого bg сбросится, и события снова сработают при следующем проходе.

VI. В комнате — iris transition

Тема мгновенно стала тёплой (indoor). Этот вагон использует data-car-transition="iris" — новый фон «вырастает» из центра экрана.

Iris-переход = эффект «открытия двери в светлую комнату». Тема меняет цвета, фон растёт из центра — две системы работают параллельно.

VII. Финал

Тема перетекла в полночь. Вагон VI уехал вверх (iris exit — схлопывается обратно в центр).

VN v3 — сводка:

• Свободное размещение: <div class="bg"> где угодно в HTML
• 4 режима размера: cover / contain / original / любой CSS-размер
• Скрипт-события: view / center / end / skip — пишите JS прямо в HTML
• Параллельные системы: theme (V8) + car (V6) работают независимо
• Skip-детект: быстрый скролл или клик по точке запускает skip-event
• Event log слева снизу показывает все события

Скролльте обратно вверх — все события сработают заново.
