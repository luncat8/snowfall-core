Глава 1

Sticky-версия: «прилипание к верху» — на CSS position: sticky, на compositor thread. JS применяет transform только когда следующий вагон начинает наступать. Когда вагон просто стоит — никаких rAF/c scroll-обработчиков не нужно, CSS делает всё сам.

Поэтому нет глича на быстром скролле: compositor обновляет sticky позицию синхронно с scroll.
